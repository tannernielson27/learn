# UI polish log

A running list for the UI polish loop: small, presentation-only changes that make LeaRN feel more finished on a classroom phone and a projector. Each row is one small PR, reviewable in a few minutes. Nothing here changes data flow, scoring, auth, realtime logic, Server Functions or `src/lib/ngn/**`.

Rules every row follows: [`04-DESIGN-DIRECTION.md`](04-DESIGN-DIRECTION.md) (transform and opacity only, reduced motion respected, no emoji, no confetti, 375px first) and [`glossary.md`](glossary.md) for words.

## How this audit was done (2026-10-15)

The local Supabase stack was not started: another project's Supabase stack was already running on this machine and about 1 GB of memory was free. The audit is from code, plus `next dev` with no database behind it for the routes that need none: `/`, `/join`, `/gallery/primitives` and `/gallery/live` (the fake room, which plays a live session in memory), screenshotted at 375, 768 and 1280. None of the four overflowed at any width. The teacher library, quiz editor, results and student home were read in code only.

## Needs a dependency

- Icons: the design direction names Lucide at 20px. Check whether every icon in use is an inline SVG copy before adding `lucide-react`; if a polish item needs many new icons, that is a dependency question for the owner.

## Needs a product decision

- The design direction says "No celebratory effects" and lists confetti, badges and streaks as anti-patterns, while this loop's brief asks for Kahoot-style fun. How far may a live-session reveal go: a settle and a colour (allowed today), or something larger for an all-correct answer?
- Should the landing page lead with "Join a live session" for students (today it is the third button, secondary style, and wraps to its own row at 1280)?
- Secondary buttons use `--line` for their border (about 1.4:1 against white). Text identifies them, so this passes WCAG, but the landing page already uses `--line-strong`. Should every secondary button take the stronger border?
- Should the host's Join code screen have a full-screen "present" mode for projectors?

## Looks broken

- Nothing broken was seen on the four routes walked. The routes behind a database were not walked this tick.
